# Git & GitHub Workflow

## Project Overview

This project demonstrates basic Git and GitHub workflow, including editing files, staging changes, committing changes, and pushing them to a remote repository.

## Why Git Makes Development Easier

Git makes development easier because it keeps a history of changes to the code. It allows developers to track what was changed and return to an earlier version when needed.

Git also helps protect the project by keeping different versions of the code. It makes collaboration easier because multiple developers can work on the same project and share their changes through a remote repository such as GitHub.

## Git Workflow

The basic Git workflow is:

1. Edit files in the working directory.
2. Use `git add` to move changes to the staging area.
3. Use `git commit` to save the changes in the local repository.
4. Use `git push` to send the commits to GitHub.
